Question-1: What are the different ways to select an element in the DOM?

Elements can be selected using modern CSS selectors like querySelector() (first match) and querySelectorAll() (all matches). You can also use traditional methods like getElementById(), getElementsByClassName(), and getElementsByTagName(). Additionally, DOM traversal properties like parentElement, children, and nextElementSibling allow relative selection.

Question-2: What is the difference between innerHTML, innerText, and textContent ?

innerHTML renders HTML tags inside an element as formatted markup, innerText extracts only the visible human-readable text while respecting CSS styles (like hiding display: none content), and textContent returns all raw text from the element—including hidden elements and script tags—without evaluating styling.

Question-3: What is event delegation in the DOM?

EEvent delegation is a design pattern in JavaScript where a single event listener is attached to a parent element instead of adding multiple listeners to individual child elements. It leverages the concept of event bubbling (where events trigger on a child and bubble up through parent nodes), allowing the parent to catch and handle events triggered by any present or dynamically added children using event.target.

Question-4: What is event bubbling in the DOM?

Event bubbling is a mechanism in the DOM where an event triggered on a specific target element first executes on that element, and then propagates ("bubbles") upward through its parent elements in the DOM hierarchy all the way up to the document object. This process allows parent elements to listen for and handle events originating from any of their child elements.

Question-5: How do you create, add, and remove elements using JavaScript?

You create new elements using document.createElement('tagName'), add them to the DOM by calling parentElement.appendChild(newElement) or parentElement.append(newElement), and remove them using element.remove() or parentElement.removeChild(element).
